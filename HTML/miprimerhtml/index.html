Trabajo Práctico N°3: Mi Primera Página Web (Estructura y Semántica HTML5)

  • Asignatura: Prácticas Profesionalizantes - Frontend Tema:

    Fundamentos de HTML5 Herramienta de apoyo: Lenguaje HTML

  • Objetivo del TP:

    Comprender la estructura básica de un documento web y aplicar etiquetas HTML5 para organizar información de texto, listas, enlaces y contenido multimedia, creando una página web personal.

Fase 1: Preparación del entorno y estructura base

  • 1-

    Crea una carpeta en tu computadora llamada miprimerhtml.

  • 2-

    Dentro de esa carpeta, crea un archivo llamado index.html y otra carpeta llamada img (aquí guardarás una imagen tuya o un avatar).

  • 3-

    Abre el archivo index.html en tu editor de código (como VS Code) y escribe la estructura básica de un documento HTML5.

    • Ayuda:

      Revisa la sección de "Estructura" en lenguajehtml.com. No olvides incluir.
